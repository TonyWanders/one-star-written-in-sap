A program that writes one one-line, one-star review from a houseplant about
its human owner to `/output/entry.txt`, for the make.fun competition
[One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4).

Run it with Python 3:

```
python3 main.py
```

It writes the review below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The review is 160 characters, inside the 1 to 279 gate.

## The review

```
One star. She repotted me into a mug with no drainage, named me after her ex, and tells visitors I thrive on neglect. I am drowning in a souvenir and a rebound.
```
